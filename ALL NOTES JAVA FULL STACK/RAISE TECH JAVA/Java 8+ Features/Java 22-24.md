## Release Overview

For interview preparation, Java 22–24 are mainly transition releases before Java 25.

---

# Java 22

## Foreign Function & Memory API

Provides a modern way for Java to interact with:

- Native libraries
    
- Memory outside the JVM
    

Designed as a safer alternative to heavy JNI usage.

Low priority for fresher interviews.

---

# Java 23

Mainly continued preview features.

Notable points:

- Markdown support in Javadoc
    
- Structured Concurrency preview
    
- Scoped Values preview
    
- Flexible Constructor Bodies preview
    
- Module Import Declarations preview
    

---

# Java 24

Important additions:

- Class-File API
    
- Ahead-of-Time loading/linking improvements
    
- Continued previews for upcoming language features
    

## Class-File API

Standard API for reading, generating, and transforming `.class` files.

---

# Interview Summary

```
Java 22 → Foreign Function & Memory API
Java 23 → Mostly preview features
Java 24 → Class-File API + AOT improvements
```

For fresher interviews, only basic awareness is enough.
