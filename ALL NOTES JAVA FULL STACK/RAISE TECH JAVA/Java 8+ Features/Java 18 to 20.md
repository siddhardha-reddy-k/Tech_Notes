## Release Overview

For interview preparation, Java 18–20 are mainly transition releases before Java 21.

Important points:

- Java 18 → UTF-8 became the default charset
    
- Java 18 → Simple Web Server
    
- Java 19–20 → Previewed major features later finalized in Java 21
    

---

# Java 18

## UTF-8 Default Charset

Java made **UTF-8** the default charset for standard APIs.

This improves consistent behavior across operating systems.

## Simple Web Server

Java 18 introduced a basic development web server.

```
jwebserver
```

Useful for quickly serving static files.

---

# Java 19–20

Mainly important for previewing modern features such as:

- Virtual Threads
    
- Record Patterns
    
- Pattern Matching for `switch`
    

These are better learned with their finalized versions in Java 21.

---

# Interview Summary

```
Java 18    → UTF-8 default + Simple Web Server
Java 19–20 → Preview releases for major Java 21 features
```
