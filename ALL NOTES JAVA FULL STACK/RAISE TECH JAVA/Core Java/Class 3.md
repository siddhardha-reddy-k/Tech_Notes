   
Naming Conventions in Java  
==========================  
In java, uppercase letters consider as different and lowercase letters consider as different. Hence we consider java is a case sensitive programming language.  
   
As we know java is a case sensitive programming language so we must and should follow naming conventions for following things.  
   
ex:  
classes  
interfaces  
variables  
methods  
keywords  
packages and   
constants   
   
classes  
--------  
In java, a class name must and should starts with uppercase letter and if it contains multiple words then each inner word must starts with initcap.  
   
ex:  
| predefined class | Userdefined class |
| --- | --- |
| System<br>FileWriter<br>BufferedReader<br>FileInputStream<br>and etc. | Test<br>TestApp<br>DemoApp<br>MyExample<br>and etc. |
   
interfaces  
---------  
In java, an interface name must and should starts with uppercase letter and if it contains multiple words then each inner word must starts with initcap.  
ex:  
| Predefined interfaces | Userdefined interfaces |
| --- | --- |
| Runnable<br>Enumeration<br>ListIterator<br>Serializable<br>and etc. | ITest<br>IDemoApp<br>IMyExample<br>IMyDemo<br>and etc. |
   
variables  
----------  
In java, a variable name must and should starts with lowercase letter and if it contains multiple words then each inner word must starts with initcap.  
   
ex:  
| Predefined variables | Userdefined variables |
| --- | --- |
| length<br>out<br>in<br>err<br>and etc. | empId<br>studName<br>deptNo<br>empSalary<br>and etc. |
   
   
methods  
--------  
In java, a method name must and should starts with lowercase letter and if it contains multiple words then each inner word must starts with initcap.  
   
ex:  
| Predefined methods | Userdefined methods |
| --- | --- |
| hashCode()<br>toString()<br>setPriority()<br>getName()<br>and etc. | getDetails()<br>calculateBill()<br>getInfo()<br>setData()<br>and etc. |
   
keywords  
--------  
In java, all keywords we need to declare under lowercase letters only.  
   
ex:  
Predefined keywords  
-------------------  
class, public, static, void, if, for , else and etc.  
   
   
packages  
----------  
In java, all packages we need to declare under lowercase letters only.  
ex:  
| Predefined packages | Userdefined packages |
| --- | --- |
| java.lang<br>java.io<br>java.util<br>java.text<br>java.time<br>java.util.stream<br>java.sql<br>and etc. | com.ihub.www<br>com.qt.www<br>com.rt.www<br>com.google.www<br>and etc. |
   
constants  
----------  
In java, all constants we need to declare under uppercase letters only.  
   
ex:  
| Predefined constants | Userdefined constants |
| --- | --- |
| MAX_PRIORITY<br>MIN_PRIORITY<br>NORM_PRIORITY<br>MAX_VALUE<br>MIN_VALUE<br>and etc. | URL<br>USERNAME<br>PASSWORD<br>LIMIT<br>and etc. |

Project  
=======  
It is a individual or collaborative enterprise carefully planned to achieve perticular goal.  
   
Technically, a project is a collection of modules.  
ex:  
Admin Module   
Customer Module   
Payment Module   
Addtocart Module   
Shipping Module   
Report Generation Module   
and etc.  
   
Every project contains two domains.  
   
1) Technical Domain   
--------------------  
Technical domain describes using which technology we developed our project.  
ex:  
Java  
   
2) Functional Domain   
-------------------  
Function domain describes specific business area.  
ex:  
Healthcare domain   
Banking domain   
ERP domain   
Insaurance domain   
and etc.
