   
Flavours in Java  
================  
We have three flavours in java.  
   
JAVA  
|-------------------------|---------------------------|  
JSE/J2SE                JEE/J2EE                JME/J2ME  
(Java Standard Edition)          (Java Enterprise Edition)  (Java Micro Edition)  
   
> Standalone App                 > Distributed App         > Mobile App  
   
> Desktop App                         > Enterprise App   
   
> Two-tier App                         > ERP App   
   
    > N-tier App   
   
> Standalone App  
----------------  
A normal java program which contains main method is called standalone application.  
ex:  

```java
class Test
{
    public static void main(String[] args)
    {
        -
        - //some code here         
        -
    }
}
```

   
> Desktop App   
-------------  
It is a software application which is used to perform perticular operation.  
ex:  
Control Panel   
Recyle Bin   
VLC media player   
and etc.

In client/server architecture, if multiple requests go to main server then main server will distribute those requests to it's parallel servers to reduce the burdun of main server such type of application is called distributed application.  
   
   
Enterprise App  
---------------  
An application which deals with large business complex logic with the help of middleware services is called enterprise application.  
   
middleware services means authentication, autherization, malware production, security and etc.  
   
ex:  
Zoom Meeting   
Skype   
Online Shopping Website   
and etc.  
   
ERP App  
---------  
ERP stands for Enterprise Resource Planning.  
   
It is a software system that integrates core operations—like finance, HR, manufacturing, and supply chain—into a single unified system.

N-tier App   
----------  
Having more then two tiers is called N-tier application.

Interview Question   
=================  
   
Q) What is Java?  
   
Java is a versatile programming language which is used to develop various applications like standalone applications, desktop applications, distributed application, enterprise applications, ERP applications, mobile applications and etc.
