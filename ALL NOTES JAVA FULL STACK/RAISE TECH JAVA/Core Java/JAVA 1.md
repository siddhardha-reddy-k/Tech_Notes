   
Q) Difference between C++ and Java?  
   
| C++ | Java |
| --- | --- |
| It is developed by Bjarne Stroustrup. | It is developed by James Gosling. |
| It is a partial object oriented<br>programming language. | It is a purely object oriented<br>programming language. |
| It is platform dependent. | It is platform independent. |
| Memory allocation and deallocation<br>will taken care by a programmer. | Memory allocation and deallocation<br>will taken care by a JVM. |
| It supports multiple inheritance. | It does not support multiple inheritance. |
| It supports pointers. | It does not support pointers. |
| It supports goto statement. | It does not support goto statement. |
| It supports operator overloading.<br>It supports preprocessor directory(#). | It does not support operator overloading.<br>It does not support preprocessor directory. |
| It contains three access specifiers i.e<br>public, private and protected. | It contains four access modifiers i.e<br>default,public,private and protected. |
| It contains three loops i.e do while<br>loop, while loop and for loop. | It contains four loops i.e do while loop,<br>while loop, for loop and for each loop. |
| To save the program we will use<br>.cpp extension. | To save the program we will use<br>.java extension. |

AI   
===  
AI stands for Artificial Intelligence.  
   
AI is a capability of a computer or a system to mimic or simulate human behaviours.  
ex:  
Thinking   
Reasioning   
Language understanding   
perception   
and etc.  
   
We have two types of AI.  
   
1) Weak AI   
----------  
It is applicable for narrow areas.  
ex:          
ChatGPT  
Google Maps   
Alexa/Siri  
and etc.  
   
2) Strong AI   
------------  
It is applicable for multiple tasks.
