# BinaryOperator

BinaryOperator<T> is a specialized Functional Interface where two inputs and the output are of the same type.

Shape: (T, T) → T

Functional method: T apply(T t1, T t2);

It is a specialization of: BiFunction<T, T, T>

**Example**

```java
BinaryOperator<Integer> add = (a, b) -> a + b;
```

Usage:

```java
int result = add.apply(10, 20);
```

Represents:

(Integer, Integer) → Integer

Another example:

```java
BinaryOperator<Integer> max = (a, b) -> a > b ? a : b;
```

**BinaryOperator vs BiFunction**

BiFunction<T, U, R>

(T, U) → R

BinaryOperator<T>

(T, T) → T

Use BinaryOperator when both inputs and the output are the same type.

**Common Usage**

Commonly used in reduction operations.

```java
numbers.stream().reduce((a, b) -> a + b);
```

The lambda:

```java
(a, b) -> a + b
```

is a BinaryOperator<Integer>.

**Utility Methods**

```java
BinaryOperator.minBy(comparator)
BinaryOperator.maxBy(comparator)
```

Used to create operators that select the minimum or maximum value based on a Comparator.

Remember:

Use BinaryOperator when combining two values of the same type into one value of the same type.
