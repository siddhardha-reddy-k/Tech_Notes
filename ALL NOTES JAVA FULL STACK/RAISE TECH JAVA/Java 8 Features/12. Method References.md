# Method References

A **Method Reference** is a short way to refer to an existing method.

It can replace a lambda that simply calls an existing method.

It uses the :: operator.

**Example**

Lambda:

```java
Function<String, Integer> function =
        str -> str.length();
```

Method Reference:

```java
Function<String, Integer> function =
        String::length;
```

The target Functional Interface provides the parameter and return type information.

**Main Types**

**1. Static Method Reference**

ClassName::staticMethod

Example:

```java
Function<Integer, Integer> function =
        MathUtil::square;
```

Equivalent lambda:

```java
number -> MathUtil.square(number)
```

**2. Instance Method Reference of a Particular Object**

object::instanceMethod

Example:

```java
Printer printer = new Printer();

Consumer<String> consumer =
        printer::print;
```

Equivalent lambda:

```java
message -> printer.print(message)
```

The method is called on an already existing object.

**3. Instance Method Reference of an Arbitrary Object**

ClassName::instanceMethod

Example:

```java
Function<String, Integer> function =
        String::length;
```

Equivalent lambda:

```java
str -> str.length()
```

The input object becomes the object on which the method is called.

**Important Points**

- Uses the :: operator.
- Refers to an existing method.
- Works with Functional Interfaces.
- Gets type information from the target Functional Interface.
- Usually replaces a lambda that directly calls an existing method.
- Does not add new logic.

Example:

```java
name -> System.out.println(name)
```

can become:

```java
System.out::println
```

A lambda with additional logic usually cannot be directly replaced.

```java
number -> number * number
```

This cannot become a Method Reference unless an existing method, such as square(), is available.
