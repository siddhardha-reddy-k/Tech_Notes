# Function Composition & Predicate Chaining

Functional programming encourages creating small reusable behaviors and combining them to create complex behavior.

**Function Composition**

Combines functions where the output of one function becomes the input of another.

**andThen()**

A.andThen(B)

Execution order:

A → B

Example:

```java
Function<Integer, Integer> multiplyBy2 = n -> n * 2;
Function<Integer, Integer> add10 = n -> n + 10;
Function<Integer, Integer> result =
        multiplyBy2.andThen(add10);

System.out.println(result.apply(5)); // 20
```

5 → ×2 → +10 → 20

**compose()**

A.compose(B)

Execution order:

B → A

Example:

```java
Function<Integer, Integer> multiplyBy2 = n -> n * 2;
Function<Integer, Integer> add10 = n -> n + 10;
Function<Integer, Integer> result =
        multiplyBy2.compose(add10);

System.out.println(result.apply(5)); // 30
```

5 → +10 → ×2 → 30

**Predicate Chaining**

Combines multiple conditions.

**and()**

p1.and(p2)

Equivalent conceptually to:

```java
value ->
p1.test(value) && p2.test(value)
```

Example:

```java
Predicate<Integer> isPositive = n -> n > 0;
Predicate<Integer> isEven = n -> n % 2 == 0;
Predicate<Integer> result =
        isPositive.and(isEven);

System.out.println(result.test(10)); // true
System.out.println(result.test(-10)); // false
```

**or()**

p1.or(p2)

Equivalent conceptually to:

```java
value ->
p1.test(value) || p2.test(value)
```

Example:

```java
Predicate<Integer> isPositive = n -> n > 0;
Predicate<Integer> isEven = n -> n % 2 == 0;
Predicate<Integer> result =
        isPositive.or(isEven);

System.out.println(result.test(-10)); // true
System.out.println(result.test(-5));  // false
```

**negate()**

p.negate()

Equivalent conceptually to:

```java
value ->
!p.test(value)
```

Example:

```java
Predicate<Integer> isEven = n -> n % 2 == 0;
Predicate<Integer> isOdd =
        isEven.negate();

System.out.println(isOdd.test(5)); // true
System.out.println(isOdd.test(4)); // false
```

**Key Difference**

Function composition

→ Output of one becomes input of next  
→ Used for transformations

Predicate chaining

→ Boolean results are combined  
→ Used for conditions

This is a core functional programming principle.
