# Default Methods in Interfaces

Java 8 introduced default methods to allow interfaces to contain method implementations.

Syntax:

```java
interface Vehicle {

    default void stop() {
        System.out.println("Vehicle stopped");
    }
}
```

An implementing class automatically inherits the default implementation unless it overrides it.

```java
class Car implements Vehicle {
}
```

Usage:

```java
Car car = new Car();
car.stop();
```

**Main Purpose**

Default methods were primarily introduced for **backward compatibility and interface evolution**.

Before Java 8:

Adding a new abstract method to an interface  
↓  
All existing implementing classes break  

With default methods:

Add a method with default implementation  
↓  
Existing implementations inherit it  
↓  
No breaking changes  

**Overriding Default Methods**

Implementing classes can override a default method:

```java
class Car implements Vehicle {

    @Override
    public void stop() {
        System.out.println("Car stopped");
    }
}
```

**Default Method Conflict Rules**

**1. Class wins over Interface**

```java
class Parent {
    public void display() {
        System.out.println("Parent");
    }
}

interface A {
    default void display() {
        System.out.println("Interface");
    }
}

class Child extends Parent implements A {
}
```

Parent.display() wins.

**2. More specific Interface wins**

```java
interface A {
    default void display() {
        System.out.println("A");
    }
}

interface B extends A {
    default void display() {
        System.out.println("B");
    }
}
```

B wins because it is more specific.

**3. Unrelated Interface Conflict**

```java
interface A {
    default void display() {
        System.out.println("A");
    }
}

interface B {
    default void display() {
        System.out.println("B");
    }
}

class Test implements A, B {

    @Override
    public void display() {
        A.super.display();
    }
}
```

The implementing class must explicitly resolve the conflict.

**Functional Interfaces**

A Functional Interface can contain default methods:

```java
@FunctionalInterface
interface Operation {

    int execute(int number);

    default void print() {
        System.out.println("Operation");
    }
}
```

It remains functional because it still has only one abstract method.

**Key Points**

- Introduced in Java 8.
- Allows method implementation inside interfaces.
- Mainly introduced for interface evolution and backward compatibility.
- Implementing classes can override them.
- Multiple default methods with the same signature can cause conflicts.
- Conflict priority: **Class > More Specific Interface > Explicit Override**.
- Default methods do not count as abstract methods for Functional Interface rules.
