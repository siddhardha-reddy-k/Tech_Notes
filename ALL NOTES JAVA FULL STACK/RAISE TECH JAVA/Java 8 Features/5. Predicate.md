# Predicate

Predicate<T> is a built-in Functional Interface from: `java.util.function`

It represents a **condition**. T → boolean

Functional method:

```java
boolean test(T t);
```

**Example**

```java
Predicate<Integer> isEven = number -> number % 2 == 0;
```

Usage:

```java
isEven.test(10); // true
isEven.test(7);  // false
```

The lambda implements:

```java
boolean test(Integer number);
```

**Common Uses**

- Filtering
- Validation
- Conditional checks

Example:

```java
stream.filter(predicate);
```

filter() expects a Predicate.

**Predicate Chaining**

```java
isPositive.and(isEven);   // &&
```

**Example:**

```java
Predicate<Integer> isEven = n -> n % 2 == 0;

Predicate<Integer> isPositive = n -> n > 0;

Predicate<Integer> isPositiveAndEven = isEven.and(isPositive);

System.out.println(isPositiveAndEven.test(10));
```

```java
isPositive.or(isNegative); // ||
isEven.negate();           // !
```

and() and or() support short-circuit evaluation.

**isEqual()**

```java
Predicate<String> isJava =
        Predicate.isEqual("Java");
```

Performs null-safe equality checking.

**Remember:** When the requirement is **Input → true/false**, use Predicate.
