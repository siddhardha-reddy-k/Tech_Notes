# UnaryOperator

UnaryOperator<T> is a specialized Functional Interface for operations where input and output are of the same type.

Shape: T → T

**It is a specialization of:** Function<T, T>

**Functional method:** T apply(T t);

**Example**

```java
UnaryOperator<Integer> square = number -> number * number;
```

Usage:

```java
int result = square.apply(5);
```

Represents:

Integer → Integer

Another example:

```java
UnaryOperator<String> toUpperCase = text -> text.toUpperCase();
```

Represents:

String → String

**Why use UnaryOperator instead of Function<T, T>?**

Both are valid.

Function<Integer, Integer>

and:

UnaryOperator<Integer>

But UnaryOperator clearly communicates that:

- There is one input
- Output is the same type

**UnaryOperator.identity()**

Returns the input unchanged.

```java
UnaryOperator<String> identity = UnaryOperator.identity();
```

Equivalent conceptually to:

```java
value -> value
```

**Real API Usage**

List.replaceAll() accepts a UnaryOperator.

```java
names.replaceAll(
    name -> name.toUpperCase()
);
```

Element
  ↓
UnaryOperator
