# Supplier

Supplier<T> is a built-in Functional Interface from: java.util.function

It represents behavior that produces a value without accepting any input.

**Shape**: () → T

**Functional method:** T get();

**Example**

```java
Supplier<String> supplier =
        () -> "Hello";
```

**Invocation:**

```java
String value = supplier.get();
```

Conceptually:

```text
get()
 ↓
Execute logic
 ↓
Return value
```

**Object Creation**

```java
Supplier<Employee> supplier =
        () -> new Employee();
```

Using Constructor Reference:

```java
Supplier<Employee> supplier =
        Employee::new;
```

Object is created when:

```java
supplier.get();
```

is called.

**Common Use Cases**

- Lazy object creation
- Generating values
- Providing default values
- Random values
- Current date/time
- Factory-like behavior
