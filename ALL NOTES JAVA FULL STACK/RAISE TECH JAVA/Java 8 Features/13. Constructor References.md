# Constructor References

A Constructor Reference is a shorthand for a lambda expression that directly creates an object using a constructor.

Syntax: ClassName::new

It works with Functional Interfaces and uses target typing to determine which constructor should be invoked.

**Example:**

```java
Function<String, Employee> creator =
        name -> new Employee(name);
```

**Constructor Reference:**

```java
Function<String, Employee> creator = Employee::new;
```

**No-argument Constructor**

Class:

```java
class Employee {
    Employee() {
    }
}
```

**Lambda:**

```java
Supplier<Employee> supplier = () -> new Employee();
```

**Constructor Reference:**

```java
Supplier<Employee> supplier = Employee::new;
```

Supplier<T> method:

```java
T get();
```

Object is created when:

```java
supplier.get();
```

is called.

**One-argument Constructor**

```java
class Employee {

    Employee(String name) {
    }
}
```

**Lambda:**

```java
Function<String, Employee> creator =
        name -> new Employee(name);
```

**Constructor Reference:**

```java
Function<String, Employee> creator = Employee::new;
```

Function<String, Employee> corresponds to:

```java
Employee apply(String name);
```

Calling:

```java
creator.apply("John");
```

conceptually executes:

```java
new Employee("John");
```

**Multiple-argument Constructor**

```java
class Employee {

    Employee(String name, int age) {
    }
}
```

Lambda:

```java
BiFunction<String, Integer, Employee> creator =
        (name, age) -> new Employee(name, age);
```

Constructor Reference:

```java
BiFunction<String, Integer, Employee> creator =
        Employee::new;
```

**Overloaded Constructors**

The target Functional Interface determines which constructor is selected.

```java
Supplier<Employee> supplier = Employee::new;
```

→ Matches Employee()

```java
Function<String, Employee> function = Employee::new;
```

→ Matches Employee(String)

```java
BiFunction<String, Integer, Employee> function = Employee::new;
```

→ Matches Employee(String, int)

**Array Constructor Reference**

Lambda:

```java
size -> new String[size]
```

Constructor Reference:

```java
String[]::new
```

Example:

```java
String[] array = list.stream()
        .toArray(String[]::new);
```

**Key Points**

- Syntax: ClassName::new
- Refers to constructor behavior.
- Does not necessarily create an object immediately.
- Object is created when the Functional Interface method is invoked.
- Target Functional Interface determines constructor parameters.
- Supports overloaded constructors.
- Supports array creation.
