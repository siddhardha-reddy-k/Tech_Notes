# Consumer

Consumer<T> is a built-in Functional Interface from: java.util.function

It represents an operation that takes an input and performs an action without returning a result.

**Shape:** T → void

**Functional method:** void accept(T t);

**Example**

```java
Consumer<String> print = text -> System.out.println(text);
```

**Invocation:**

```java
print.accept("Hello");
```

The lambda implements conceptually:

```java
void accept(String text)
```

**Common Use Cases**

- Printing values
- Logging
- Updating objects
- Saving data
- Performing actions on collection elements

Example:

```java
names.forEach(
    name -> System.out.println(name)
);
```

forEach() accepts a Consumer.

Conceptually:

```java
for (String name : names) {
    consumer.accept(name);
}
```

**andThen()**

Consumers can be chained.

```java
Consumer<String> print =
        text -> System.out.println(text);

Consumer<String> printLength =
        text -> System.out.println(text.length());

Consumer<String> combined =
        print.andThen(printLength);
```

**Execution:**

```java
combined.accept("Java");
```

Output:

```text
Java
4
```

Conceptually:

```java
text -> {
    print.accept(text);
    printLength.accept(text);
};
```

Both Consumers receive the **same input**.
