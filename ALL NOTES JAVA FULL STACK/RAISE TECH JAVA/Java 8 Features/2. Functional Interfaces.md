# Functional Interfaces

A Functional Interface is an interface that contains exactly **one abstract method**. It is also called a **SAM (Single Abstract Method) interface**.

Functional Interfaces provide the target type for Lambda Expressions.

Example:

```java
@FunctionalInterface
interface Operation {
    int execute(int number);
}
```

Lambda implementation:

```java
Operation square = number -> number * number;
```

The compiler checks the single abstract method:

```java
int execute(int number);
```

and maps the lambda accordingly.

Conceptually:

```java
Operation square = new Operation() {
    @Override
    public int execute(int number) {
        return number * number;
    }
};
```

**Why exactly one abstract method?**

A lambda must have one unambiguous method to implement.

If an interface had multiple abstract methods, Java would not know which method the lambda represents.

**Rules**

A Functional Interface can contain:

- Exactly one abstract method
- Multiple default methods
- Multiple static methods
- Methods inherited from Object

Example:

```java
@FunctionalInterface
interface Operation {

    int execute(int number);

    default void printInfo() {
        System.out.println("Operation");
    }

    static void help() {
        System.out.println("Help");
    }
}
```

This is still a Functional Interface because only execute() is abstract.

**@FunctionalInterface**

@FunctionalInterface is optional.

It does not make an interface functional. The interface is functional based on the one-abstract-method rule.

The annotation:

- Documents the intention
- Provides compile-time validation
- Prevents accidentally adding another abstract method

Example:

```java
@FunctionalInterface
interface Calculator {
    int calculate(int a, int b);
}
```

Adding another abstract method causes a compile-time error.

**Object methods**

Methods that override Object methods such as:

- equals()
- hashCode()
- toString()

do not count toward the Functional Interface's abstract method limit.

**Lambda compatibility**

The Functional Interface's abstract method determines:

- Number of lambda parameters
- Parameter types
- Return type

Example:

```java
interface Calculator {
    int calculate(int a, int b);
}
```

Compatible lambda:

```java
Calculator add = (a, b) -> a + b;
```

**Types of Functional Interface methods**

No parameter, no return:

```java
interface Task {
    void execute();
}

Task task = () -> System.out.println("Running");
```

Parameter, no return:

```java
interface Printer {
    void print(String message);
}

Printer printer = message -> System.out.println(message);
```

Parameter and return:

```java
interface Square {
    int calculate(int number);
}

Square square = number -> number * number;
```

Multiple parameters and return:

```java
interface Calculator {
    int calculate(int a, int b);
}

Calculator add = (a, b) -> a + b;
```

**Key Concept**

Functional Interface  
↓  
Single Abstract Method  
↓  
Defines parameters + return type  
↓  
Provides context for Lambda  
↓  
Lambda implements that method  

A lambda gets its meaning from the Functional Interface's method signature. This is commonly referred to as **target typing**.
