# Function<T, R>

Function<T, R> is a built-in Functional Interface from: java.util.function

It represents a transformation.

Shape: T → R

- T → Input type
- R → Return type

Functional method: R apply(T t);

**Examplea**

```java
Function<Integer, Integer> square = number -> number * number;
```

Invocation:

```java
square.apply(5); // 25
```

Conceptually:

Input → Transformation → Output

**Different Input and Output Types**

```java
Function<String, Integer> length =
        text -> text.length();
```

Represents:

String → Integer

**Function Composition**

**andThen()**

A.andThen(B)

Execution order:

A → B

Example:

```java
Function<Integer, Integer> multiplyBy2 =
        n -> n * 2;

Function<Integer, Integer> add10 =
        n -> n + 10;

Function<Integer, Integer> result =
        multiplyBy2.andThen(add10);
```

For input 5:

5 → ×2 → +10  
5 → 10 → 20

**Conceptually:**

```java
input -> B.apply(A.apply(input))
```

**compose()**

A.compose(B)

Execution order:

B → A

Example:

```java
Function<Integer, Integer> result =
        multiplyBy2.compose(add10);
```

For input 5:

5 → +10 → ×2  
5 → 15 → 30

**Conceptually:**

```java
input -> A.apply(B.apply(input))
```

**Function.identity()**

Returns the input unchanged.

```java
Function<String, String> identity = Function.identity();
```

Equivalent conceptually to:

```java
value -> value
```

Use Function whenever the requirement is:

Take an input, transform it, and return a result.
