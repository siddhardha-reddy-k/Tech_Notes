# Built-in Functional Interfaces

Java 8 provides commonly used Functional Interfaces in:

`java.util.function`

The main interfaces are:

| Interface | Input | Output | Purpose |
| --- | --- | --- |
| Predicate<T> | T | boolean | Testing/condition |
| Function<T,R> | T | R | Transformation |
| Consumer<T> | T | void | Perform action |
| Supplier<T> | None | T | Supply/produce |
| UnaryOperator<T> | T | T | Same-type transformation |
| BinaryOperator<T> | T, T | T | Same-type combination |

**Why Built-in Functional Interfaces?**

Before Java 8, developers often created custom interfaces for common behavior patterns.

Example:

```java
interface NumberChecker {
    boolean check(Integer number);
}
```

Java provides:

`Predicate<Integer>`

This standardizes common functional behavior across Java APIs.

**Connection with Streams**

Streams heavily use these interfaces:

```text
stream.filter(...)  → Predicate
stream.map(...)     → Function
stream.forEach(...) → Consumer
```

Example:

```java
numbers.stream()
       .filter(n -> n > 10)
       .map(n -> n * 2)
       .forEach(n -> System.out.println(n));
```

Mapping:

```text
n -> n > 10                 → Predicate
n -> n * 2                  → Function
n -> System.out.println(n)  → Consumer
```

**Key Concept**

Built-in Functional Interfaces represent common shapes of behavior:

```text
Input → boolean       Predicate

Input → Output        Function

Input → action        Consumer

No Input → Output     Supplier

T → T                 UnaryOperator

(T, T) → T            BinaryOperator
```

They provide standardized contracts so developers don't need to repeatedly create custom Functional Interfaces.
