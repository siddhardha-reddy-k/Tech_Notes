# 23. Stream-Processing Vocabulary

## Source

Where elements being processed originate.

Examples:

- collection
- array
- generated sequence

---

## Intermediate Operation

An operation that performs part of a processing chain and produces another stage.

---

## Terminal Operation

The final operation that produces a result or side effect.

---

## Lazy Evaluation

Delaying computation until the result is actually required.

---

## Short-Circuiting

Ending processing early once the final result is already known.

---
