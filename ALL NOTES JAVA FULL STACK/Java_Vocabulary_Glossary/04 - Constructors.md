# 4. Constructors

## Constructor

A special class member used during object creation to initialize an object.

---

## Default Constructor

A constructor provided automatically by the compiler when no constructor is explicitly declared.

---

## No-Argument Constructor

A constructor that receives no arguments.

---

## Parameterized Constructor

A constructor that accepts parameters.

---

## Constructor Overloading

Having multiple constructors with different parameter lists.

---

## Constructor Chaining

Calling one constructor from another constructor.

Using:

```java
this()
```

or:

```java
super()
```
