# 14. Arrays

## Array

A fixed-size structure containing multiple elements of the same type.

---

## Element

An individual item stored inside an array or collection.

---

## Index

The position of an element.

Java arrays use zero-based indexing.

---

## Length

The number of elements an array can contain.

---

## Traversal

Going through the elements of a data structure.

---

## Array Initialization

Creating an array and/or supplying its initial elements.

---
