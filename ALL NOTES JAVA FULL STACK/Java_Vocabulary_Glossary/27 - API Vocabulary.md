# 27. API Vocabulary

## API

Application Programming Interface.

A defined way for software components to interact.

---

## Library

A collection of reusable functionality.

---

## Framework

A reusable structure that provides infrastructure and controls significant parts of application flow.

---

## Dependency

Something another class or component needs in order to work.

---

## Dependency Injection

Providing a class with its required dependencies from outside rather than creating them directly inside the class.

---

## Configuration

Settings controlling how an application or component behaves.

---

## Convention

A commonly accepted way of structuring or writing something.

---

## Boilerplate

Repetitive structural code that often contains little application-specific logic.

---
