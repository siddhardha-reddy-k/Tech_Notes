# 8. Interfaces and Abstraction

## Interface

A contract describing behavior that implementing classes must provide.

---

## Implementation

The actual working code that performs some behavior.

For example, an interface may declare a method and a class provides the implementation of that method.

---

## Implement

To provide the working code required by a contract or abstract declaration.

---

## `implements`

Keyword used to declare that a class follows an interface contract.

Example:

```java
class Report implements Printable
```

---

## Abstract Class

A class designed mainly to be extended and which may contain both abstract and implemented behavior.

---

## Abstract Method

A method declared without a body.

---

## Concrete Class

A complete class that can normally be instantiated.

---

## Concrete Method

A method containing an implementation/body.

---

## Contract

The behavior that another class or component is expected to provide.

---
