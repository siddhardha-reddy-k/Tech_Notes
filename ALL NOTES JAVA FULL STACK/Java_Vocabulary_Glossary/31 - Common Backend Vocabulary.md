# 31. Common Backend Vocabulary

## Endpoint

A specific API location exposing some functionality.

---

## Controller

A component commonly responsible for receiving incoming operations and coordinating what happens next.

---

## Service

A component commonly containing application or business logic.

---

## Repository

A component responsible for data-access operations.

---

## Entity

An object commonly associated with persistent/database data.

---

## DTO

**Data Transfer Object**

An object used mainly to transfer data between parts of an application.

---

## Persistence

Keeping data beyond the immediate execution of the program.

---

## Business Logic

The actual rules and operations representing what an application should do.

---

## Data Access

Reading and writing application data from persistent storage.

---
