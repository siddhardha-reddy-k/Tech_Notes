# 16. Collections

## Collection

A structure used to store groups of objects.

---

## Collection Framework

Java APIs used for storing and manipulating groups of objects.

---

## Duplicate

Something that appears more than once.

---

## Ordering

The sequence in which elements are maintained.

---

## Sorting

Arranging elements according to some order.

---

## Natural Ordering

The default ordering defined by a type.

Usually related to `Comparable`.

---

## Custom Ordering

Ordering explicitly defined by the developer.

Usually using `Comparator`.

---

## Comparable

Interface through which a class defines its natural ordering.

---

## Comparator

Defines how two objects should be compared for ordering.

---

## Iterator

An object used to move through elements one at a time.

---

## Iterable

Something capable of providing an `Iterator`.

---

## Traversal

Moving through elements of a data structure.

---
