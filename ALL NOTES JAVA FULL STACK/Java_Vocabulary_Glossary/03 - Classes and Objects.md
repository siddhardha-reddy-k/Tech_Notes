# 3. Classes and Objects

## Class

A blueprint defining the state and behavior of objects.

---

## Object

An instance created from a class.

---

## Instance

An object created from a particular class.

Example:

```java
Employee emp = new Employee();
```

`emp` refers to an instance of `Employee`.

---

## Instantiation

Creating an instance of a class.

Example:

```java
new Employee();
```

---

## Object Creation

The process of creating an object.

Example:

```java
Employee emp = new Employee();
```

---

## State

The current data maintained by an object.

Usually represented using fields.

---

## Behavior

What an object can do.

Usually represented using methods.

---
