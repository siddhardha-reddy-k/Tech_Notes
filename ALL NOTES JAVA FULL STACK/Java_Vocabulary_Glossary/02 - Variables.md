# 2. Variables

## Local Variable

A variable declared inside a:

- method
- constructor
- block

---

## Instance Variable

A field belonging to each object of a class.

Also called:

**instance field**

---

## Static Variable

A field belonging to the class itself rather than individual objects.

Also called:

**class variable**

---

## Field

A variable declared directly inside a class.

Can be:

- instance field
- static field

---

## Member

Something declared inside a class.

Examples:

- fields
- methods
- constructors
- nested classes

---
