# 24. Multithreading

## Process

A running program with its own execution environment.

---

## Thread

An independent path of execution inside a process.

---

## Main Thread

The initial thread executing a Java application.

---

## Multithreading

Using multiple threads within one process.

---

## Concurrency

Multiple tasks making progress during overlapping periods of time.

---

## Parallelism

Multiple tasks actually executing simultaneously.

---

## Synchronization

Coordinating access to shared resources.

---

## Shared Resource

Data or a resource accessed by multiple threads.

---

## Race Condition

A problem where the result depends on unpredictable timing between threads.

---

## Thread Safety

Code behaving correctly when multiple threads access it.

---

## Deadlock

A situation where threads permanently wait for one another.

---

## Lock

A mechanism used to control access to a shared resource.

---

## Atomic Operation

An operation treated as one indivisible action from the perspective of other threads.

---

## Executor

An abstraction used to execute submitted tasks.

---

## Thread Pool

A reusable collection of worker threads.

---

## Task

A unit of work to be executed.

---

## Callable

A task capable of producing a result.

---

## Runnable

A task representing work to execute without returning a result.

---

## Future

Represents a result that may become available later from another computation.

---
