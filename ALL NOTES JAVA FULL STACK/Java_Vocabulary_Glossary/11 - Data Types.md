# 11. Data Types

## Reference Type

A type where variables can refer to objects.

Examples include:

- classes
- arrays
- interfaces
- enums
- records

---

## Wrapper Class

Object representation corresponding to a primitive.

Examples:

- `Integer`
- `Double`
- `Boolean`
- `Character`

---

## Autoboxing

Automatic conversion from primitive to wrapper.

Example:

```text
int → Integer
```

---

## Unboxing

Automatic conversion from wrapper to primitive.

Example:

```text
Integer → int
```

---

## Widening Conversion

Converting a smaller compatible primitive representation into a larger one.

Example:

```text
int → long
```

Usually automatic.

---

## Narrowing Conversion

Converting a larger primitive representation into a smaller one.

Example:

```text
double → int
```

Usually requires explicit casting.

---

## Casting

Explicitly treating or converting something as another compatible type.

---

## Upcasting

Treating a subclass object through a superclass or interface reference.

---

## Downcasting

Casting a superclass/interface reference back to a compatible subclass type.

---
