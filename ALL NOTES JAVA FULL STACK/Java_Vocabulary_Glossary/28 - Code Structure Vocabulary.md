# 28. Code Structure Vocabulary

## Block

A group of statements enclosed inside:

```java
{ }
```

---

## Nested

Something located inside another structure.

Examples:

- nested loop
- nested `if`
- nested class

---

## Outer

The containing structure.

---

## Inner

The structure located inside another structure.

---

## Nested Class

A class declared inside another class.

---

## Inner Class

A non-static nested class associated with an instance of its outer class.

---

## Anonymous Class

A class implementation created without declaring a normal named class.

---

## Enum

A special type representing a fixed set of constants.

---

## Record

A compact Java type commonly used to represent data.

---

## Annotation

Metadata attached to Java code.

Example:

```java
@Override
```

---
