# 30. Important Vocabulary Differences ⭐

## Declare vs Initialize

### Declare
Introduce the variable.

### Initialize
Give it its initial data.

## Initialize vs Assign

### Initialize
Give something its first data/state.

### Assign
Give data to a variable.

## Assign vs Reassign

### Assign
Give data to a variable.

### Reassign
Replace what the variable currently holds.

## Instantiate vs Initialize

### Instantiate
Create an object.

### Initialize
Give something its initial state/data.

## Create vs Instantiate

### Create
General word.

### Instantiate
Specifically create an instance of a class.

## Declare vs Define

### Declare
Introduce something.

### Define
Provide its complete structure or behavior.

## Implement vs Override

### Implement
Provide working behavior required by a contract or abstract declaration.

### Override
Provide a new version of inherited behavior.

## Call vs Invoke

Practically the same for normal conversation.

## Parameter vs Argument

### Parameter
Declared by the method.

### Argument
Supplied while calling the method.

## Execute vs Evaluate

### Execute
Run an instruction or block.

### Evaluate
Determine the result of an expression.

## Check vs Compare

### Check
Determine whether some condition is true.

### Compare
Examine two things relative to each other.

## Access vs Retrieve

### Access
Reach/use some data directly.

### Retrieve
Get existing data.

## Retrieve vs Fetch

### Retrieve
General word meaning get existing data.

### Fetch
Commonly implies getting data from somewhere else.

## Iterate vs Traverse

### Iterate
Repeatedly process elements.

### Traverse
Move through an entire data structure.

## Iterate vs Access

### Iterate
Move repeatedly through multiple elements.

### Access
Reach a specific element.

## Index vs Element

### Index
Position.

### Element
The actual item at that position.

## Increment vs Update

### Increment
Specifically increase a number.

### Update
General word meaning modify existing data.

## Modify vs Mutate

### Modify
General word for change.

### Mutate
Change the internal state of an existing object.

## Convert vs Cast

### Convert
General transformation from one representation/type to another.

### Cast
Explicit Java type operation involving compatible types.

## Return vs Print

### Return
Send a result back to the caller.

### Print
Display something as output.

## Print vs Produce

### Print
Display something.

### Produce
Generate a result.

## Store vs Hold

### Store
Usually describes putting data somewhere.

### Hold
Describes what is currently there.

## Add vs Insert

### Add
General operation of adding something.

### Insert
Place something at a particular position.

## Add vs Append

### Add
General addition.

### Append
Add specifically to the end.

## Remove vs Delete

### Remove
Take something out of a data structure.

### Delete
Usually permanently remove stored data.

## Check vs Validate

### Check
General test.

### Validate
Check whether something satisfies defined rules.

## Match vs Equal

### Equal
Two things represent the same data according to some equality rule.

### Match
Something satisfies or corresponds to another pattern, condition, or target.

## Process vs Transform

### Process
General operation on data.

### Transform
Specifically change data into another form.

## Calculate vs Compute

Both usually mean obtaining a result through processing.
