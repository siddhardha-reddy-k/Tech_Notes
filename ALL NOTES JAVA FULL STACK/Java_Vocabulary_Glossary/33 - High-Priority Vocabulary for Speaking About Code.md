# Core Speaking Pattern ⭐

When explaining code, try to naturally form explanations using these verbs.

Example:

```java
for (int i = 0; i < names.length; i++) {
    System.out.println(names[i]);
}
```

Good explanation:

> We declare and initialize `i` with `0`.
> The condition checks whether `i` is less than the array length.
> The loop iterates from index `0` up to `names.length - 1`.
> During each iteration, `names[i]` accesses the element at the current index.
> The element is passed to `println()`, which prints it.
> After each iteration, `i` is incremented by one.
