# 9. Access Control

## Access Modifier

Controls where something can be accessed.

Java provides:

- `public`
- `protected`
- package-private
- `private`

---

## Public

Accessible from anywhere where the containing type itself is accessible.

---

## Private

Accessible only inside the declaring class.

---

## Protected

Accessible within the package and under specific inheritance rules.

---

## Package-Private

Accessible within the same package.

Used when no explicit access modifier is provided.

---

## Visibility

Where something can be seen or accessed from.

---

## Accessibility

Whether code is allowed to access something.
