# 29. Common Code-Explanation Vocabulary ⭐

This is one of the most important sections.

These are the words you use while **explaining what Java code is doing**.

## Declare

Introduce something such as a variable, method, or class.

> "We declare an integer variable called `count`."

## Initialize

Give something its initial data.

> "We initialize `count` with zero."

## Assign

Give data to a variable.

> "We assign the result to `total`."

## Reassign

Replace what a variable currently holds.

> "`count` is reassigned with the new result."

## Hold

Used when describing what a variable currently contains.

> "`count` holds the number of elements."

## Store

Keep data somewhere.

> "The result is stored in the variable."

## Instantiate

Create an instance of a class.

> "We instantiate the `Employee` class."

## Create

General-purpose word meaning make something.

> "We create an array."

## Construct

Create and initialize an object, usually through a constructor.

> "The constructor constructs the object."

## Reference

Refer to another object.

> "`emp` references an `Employee` object."

## Point To

Common conversational way of describing an object reference.

> "`emp` points to the newly created object."

## Access

Reach or use something.

> "We access the element at index `i`."

## Read

Obtain data without changing it.

> "We read the element from the array."

## Write

Place or change data somewhere.

> "We write the new data into the array."

## Retrieve

Get existing data.

> "We retrieve the employee using the ID."

## Fetch

Retrieve data, especially from an external source.

## Get

A simple conversational word for retrieving something.

## Set

Give or change some data.

## Pass

Send an argument into a method.

## Receive

Accept incoming data.

## Accept

Another useful word for method parameters.

## Return

Send a result or control back to the caller.

## Produce

Generate a result.

## Invoke

Call a method.

## Call

Common conversational form of **invoke**.

## Execute

Run an instruction, method, block, or program.

## Evaluate

Determine the result of an expression.

## Check

Examine whether something is true or valid.

## Test

Check something against a condition.

## Compare

Examine two things relative to each other.

## Match

Determine whether something corresponds to something else.

## Satisfy

Meet the requirements of a condition.

## Meet a Condition

Natural alternative to **satisfy**.

## Validate

Check whether something follows required rules.

## Verify

Confirm that something is correct.

## Iterate

Repeatedly process items or repeat an operation.

## Iterate Over

Very common phrasing.

## Loop Through

Less formal but very natural.

## Traverse

Move through a data structure.

## Access by Index

Retrieve an element using its numeric position.

## Increment

Increase a numeric variable.

## Decrement

Decrease a numeric variable.

## Update

Change existing data.

## Modify

Change something.

## Mutate

Change the state of an existing object.

## Transform

Take data and produce another form.

## Convert

Change something from one representation or type into another.

## Cast

Explicitly treat something as another compatible type.

## Process

General-purpose word for performing operations on data.

## Handle

Deal with a situation or input.

## Perform

Carry out an operation.

## Calculate

Produce a numeric/computed result.

## Compute

More technical alternative to **calculate**.

## Add

Put another item into something.

## Insert

Place something at a particular position or location.

## Append

Add something to the end.

## Remove

Take something out.

## Delete

Usually means permanently remove stored data.

## Replace

Substitute one thing with another.

## Swap

Exchange the positions of two things.

## Merge

Combine multiple things.

## Combine

General word for joining things together.

## Concatenate

Join strings or sequences end-to-end.

## Split

Divide something into smaller parts.

## Parse

Interpret textual/raw data as structured data.

## Format

Arrange data into a particular representation.

## Generate

Create something automatically.

## Filter

Keep only items satisfying a condition.

## Sort

Arrange elements according to an ordering rule.

## Search

Look for something.

## Find

Locate something.

## Locate

Determine where something is.

## Contains

Used when something has a particular element or data.

## Exists

Used to describe whether something is present.

## Duplicate

Create another identical occurrence or describe repeated data.

## Skip

Ignore something or avoid executing part of the logic.

## Enter

Begin executing a particular block.

## Exit

Leave a block, loop, method, or program.

## Terminate

Completely stop something.

## Continue Execution

Move on with the remaining program execution.

## Trigger

Cause something to start.

## Delegate

Give responsibility to another object or method.

## Propagate

Pass something further through the call chain.

## Resolve

Determine what something refers to.

## Select

Choose one thing from multiple possibilities.

## Determine

Figure out the result or state of something.

## Execute Sequentially

Execute operations one after another.

## Repeat

Execute something multiple times.

## Process Each Element

Extremely useful general phrase.
