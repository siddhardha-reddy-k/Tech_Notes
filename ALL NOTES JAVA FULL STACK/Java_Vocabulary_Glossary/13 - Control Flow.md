# 13. Control Flow

## Control Flow

The order in which instructions execute.

---

## Conditional Statement

A statement that chooses what code should execute depending on a condition.

Examples:

- `if`
- `else`
- `switch`

---

## Condition

An expression evaluated as either `true` or `false`.

---

## Branching

Choosing between different execution paths.

---

## Iteration

Repeated execution of code.

---

## Loop

A structure used to execute code repeatedly.

Examples:

- `for`
- `while`
- `do-while`

---

## Loop Body

The code executed during each iteration of a loop.

---

## Loop Variable

A variable used during loop execution.

---

## Counter

A variable used to count occurrences or iterations.

---

## Index

The numeric position of an element in an indexed structure.

Indexes normally start from `0`.

---

## Iteration Variable

A variable representing the current item during iteration.

Example:

```java
for (String name : names)
```

`name` is the iteration variable.

---

## Infinite Loop

A loop that continues indefinitely unless something stops it.

---
