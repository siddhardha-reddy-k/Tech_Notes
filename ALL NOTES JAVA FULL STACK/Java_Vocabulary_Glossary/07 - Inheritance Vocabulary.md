# 7. Inheritance Vocabulary

## Parent Class

The class being inherited from.

Also called:

- superclass
- base class

---

## Child Class

The class inheriting another class.

Also called:

- subclass
- derived class

---

## Superclass

A parent class in an inheritance relationship.

---

## Subclass

A class derived from another class.

---

## Base Class

Another common term for superclass.

---

## Derived Class

Another common term for subclass.

---

## Inheritance Hierarchy

The parent-child structure created through inheritance.

---

## `extends`

Keyword used to create class inheritance.

---

## `super`

Used to refer to superclass constructors or accessible members.

---

## `this`

Refers to the current object.

---
