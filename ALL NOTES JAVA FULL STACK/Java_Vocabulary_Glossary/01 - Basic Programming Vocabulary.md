# 1. Basic Programming Vocabulary

## Statement

A complete instruction executed by the program.

Example:

```java
int age = 20;
```

---

## Expression

A piece of code that produces a result.

Examples:

```java
10 + 20
age > 18
name.length()
```

---

## Declaration

Introducing a variable, method, class, interface, etc.

Example:

```java
int age;
```

Here, `age` is declared.

---

## Initialization

Giving something its initial data/state.

```java
int age = 20;
```

Here, `age` is initialized with `20`.

---

## Assignment

Giving data to a variable.

```java
age = 25;
```

---

## Reassignment

Assigning new data to a variable that already contains data.

```java
age = 30;
```

---

## Identifier

The name given to something in Java.

Examples:

- variable name
- method name
- class name
- interface name

---

## Literal

Data written directly in code.

Examples:

```java
10
3.14
'A'
"Hello"
true
null
```

---

## Variable

A named storage location used to hold data.

Example:

```java
int age = 20;
```

`age` is the variable.

---

## Constant

Something intended not to change after initialization.

Usually created using:

```java
final
```

---

## Reference

Something that refers to an object.

Example:

```java
Employee emp;
```

`emp` can hold a reference to an `Employee` object.

---

## Scope

The region of code where something can be accessed.

Examples:

- local scope
- method scope
- class scope
- block scope

---

## Lifetime

How long a variable or object exists while the program runs.

---
