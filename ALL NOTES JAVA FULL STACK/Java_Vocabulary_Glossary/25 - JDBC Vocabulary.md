# 25. JDBC Vocabulary

## JDBC

Java Database Connectivity.

Java API for communicating with relational databases.

---

## Driver

Software that allows Java to communicate with a particular database system.

---

## Connection

An active communication session with a database.

---

## Statement

An object used to send SQL commands to a database.

---

## PreparedStatement

A parameterized SQL statement prepared for execution.

---

## ResultSet

Represents rows returned by a database query.

---

## Query

An instruction sent to a database.

---

## Parameter Binding

Supplying actual data for placeholders in a prepared statement.

---

## Transaction

A group of database operations treated as one logical unit.

---

## Commit

Make transaction changes permanent.

---

## Rollback

Undo changes made during the current transaction.

---

## Auto-Commit

Automatically commit database operations.

---

## Batch Processing

Sending multiple database operations together for execution.

---
