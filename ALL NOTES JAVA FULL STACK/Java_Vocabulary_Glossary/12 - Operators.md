# 12. Operators

## Operator

A symbol that performs an operation.

Examples:

```text
+
-
*
/
==
```

---

## Operand

The data an operator operates on.

Example:

```java
10 + 20
```

`10` and `20` are operands.

---

## Arithmetic Operator

An operator used for mathematical operations.

---

## Relational Operator

An operator used to compare things.

Examples:

```text
>
<
>=
<=
==
!=
```

---

## Logical Operator

An operator used with boolean expressions.

Examples:

```text
&&
||
!
```

---

## Assignment Operator

An operator used while assigning data.

Examples:

```text
=
+=
-=
```

---

## Unary Operator

An operator that works with one operand.

---

## Binary Operator

An operator that works with two operands.

---

## Ternary Operator

Conditional operator using three operands.

```java
condition ? result1 : result2
```
