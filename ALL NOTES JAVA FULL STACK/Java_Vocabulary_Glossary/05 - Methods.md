# 5. Methods

## Method

A named block of code representing some behavior or operation.

---

## Method Declaration

Declaring information about a method such as:

- name
- parameters
- return type
- modifiers

---

## Method Definition

The complete method including its body.

---

## Method Signature

The method name together with its parameter types.

Example:

```java
add(int, int)
```

The return type is not part of a Java method signature.

---

## Method Body

The code inside:

```java
{ }
```

that defines what the method does.

---

## Method Call

Calling a method so its code can execute.

Example:

```java
employee.getName();
```

---

## Invocation

The technical term for calling a method.

```java
employee.getName();
```

invokes `getName()`.

---

## Caller

The code or method that invokes another method.

---

## Callee

The method being invoked.

---

## Return

Sending control or a result back to the caller.

---

## Return Type

The type of result a method returns.

---

## Parameter

A variable declared in a method definition.

```java
void print(String name)
```

`name` is a parameter.

---

## Argument

The actual data passed during a method call.

```java
print("Sid");
```

`"Sid"` is an argument.

---

## Method Overloading

Multiple methods with the same name but different parameter lists.

---

## Method Overriding

A subclass providing its own implementation of an inherited method.

---
